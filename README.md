# Kids Learning Prototype V2

Druga wersja prototypu do testów na telefonie.

## Najważniejsze zmiany
- matematyka: liczby i działanie są na pierwszym planie, kropki są tylko małą podpowiedzią
- kodowanie: legenda pozostaje cały czas widoczna, a dziecko wpisuje litery do pól
- logika: dziecko odtwarza wzór poprzez zaznaczanie kropek na pustej siatce 5x5
- jedno zadanie = jeden ekran
- feedback tylko: `Super!` albo `Spróbuj jeszcze raz`

## Zawartość
- ekran z imieniem
- 10 przykładowych zadań
- dodawanie z wizualną podpowiedzią
- odejmowanie
- brakująca liczba
- ciąg logiczny
- element niepasujący
- pamięć obrazków
- kodowanie symboli na litery
- odwzorowanie wzoru na siatce
- sudoku 4x4
- ekran końcowy

## Uruchomienie lokalne

```bash
npm install
npm start
```

## GitHub + Railway

1. Utwórz nowe repozytorium na GitHubie lub podmień pliki w istniejącym repo.
2. Wrzuć do niego wszystkie pliki z tego folderu.
3. W Railway wybierz projekt podłączony do tego repozytorium.
4. Railway uruchomi ponowny deploy automatycznie po pushu.
5. Jeśli tworzysz nowy projekt: `New Project` -> `Deploy from GitHub repo`.
6. W `Settings` -> `Networking` wygeneruj publiczną domenę Railway.

Na tym etapie nie jest potrzebna baza danych ani osobny backend.
